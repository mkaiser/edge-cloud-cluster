# Names below are VERBATIM from the 2026.1 installer's own reference config,

#   xsetup --batch ConfigGen --product Vivado --edition "Vivado Design Suite"
# and dumped from /root/.Xilinx/install_config.txt. Do NOT invent names — 2026.1
# renamed almost everything vs earlier releases ("Artix-7" -> "Artix-7 FPGAs",

# family entries were replaced by per-part xcv*/xave*/xc2v* modules). Any unknown

# command above and realign, then bump IMAGE_TAG in .gitlab-ci.yml.

# 2026.1 has a SINGLE edition ("Vivado Design Suite") — the ML Standard/Enterprise
# split is gone; licensing (not the installer) decides the feature tier.
#
# Selection: Vivado only, trimmed device set — 7-series (Artix/Kintex/Zynq-7000),
# Kintex/Virtex UltraScale+ and Zynq UltraScale+ MPSoC. Everything else off,
# including Vitis Model Composer and DocNav (both default to 1 in the reference
# config and add GBs). Enable a family by flipping its :0 to :1, then bump
# IMAGE_TAG in .gitlab-ci.yml — and keep build-files-configmap.yaml in sync.
# ⚠ DO NOT COPY KEYS FROM THE 2024.1 CONFIG. This file intentionally has NO
# EnableDiskUsageOptimization and NO CreateShortcutsForAllUsers: the 2026.1 installer's own
# reference config does not emit them, and an unknown KEY aborts xsetup exactly as an unknown
# module name does. Diffed against eda-xilinx-2024-1/install_config.txt — those
# two keys are the only difference in key set, and their absence here is correct.
#
# ⚠ Nor are the MODULE NAMES interchangeable: 2026.1 uses the long spellings
# ("Artix-7 FPGAs", "Zynq-7000 All Programmable SoC") and Edition="Vivado Design Suite",
# where 2024.1 uses short names and "Vivado ML Standard". Verified identical to the
# long-standing native 2026.1 config (was remote-desktop/modules/vivado/install_config.txt,
# deleted with that app; see git history if the original is ever needed).
#
# ⚠ DocNav stays :0. On 2024.1 it hung xsetup's FINALISATION step twice (pipelines #46/#51):
# files reach 100% (Done), then the JVM parks forever on futex_do_wait with 0% CPU because
# DocNav fetches its online doc catalogue (resources/xhubs.xml, xdocs.xml) from AMD and this
# lab's egress is filtered. Not a timeout and not cpu throttling — both were tested and
# disproven. Do not enable it here without a working HTTPS path AND a completed build.
